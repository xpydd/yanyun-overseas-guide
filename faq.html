Troubleshooting

Overseas Player FAQ

Common setup and gameplay problems collected into a static FAQ page for search and sharing.

Game will not launch

Run as administrator, verify files, update GPU drivers, check antivirus rules, and install DirectX or Visual C++ runtimes.

Disk space requirement

Plan for around 100GB SSD for the standard package. Lite installations may need less, but SSD remains recommended.

Low FPS or stutter

Lower graphics settings, close background apps, update drivers, and use system performance mode.

Crashes during gameplay

Verify files, update drivers, reduce graphics load, check thermals, and disable overlays.

Cannot connect to server

Check connection, disable VPN or proxy, flush DNS, review firewall rules, and try another server region.

Beginner martial art

Start with Nameless Sword + Nameless Spear if you want a forgiving first-week build.
