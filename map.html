Exploration Principle

Mark Routes, Not Just Places

For a live open-world wuxia game, a useful map guide is a route system: waypoint first, nearby rewards second, bosses and event portals third, full cleanup last.

Route Operations

Every Map Note Needs A Job

A region card should tell the player whether to move, farm, fight, verify, or leave it for later. That is the difference between a pretty map and a usable route.

Qinghe

Starter region for first route planning, early waypoints, and low-pressure encounters.

  • Unlock nearby waypoints before side quests.
  • Mark short encounters for fragmented sessions.
  • Track chests near teleport points before long detours.
  • Use hidden entrances as optional notes until verified.

Kaifeng

Main hub for vendors, social systems, dense quest errands, and maintenance loops.

  • Separate story errands from daily routine tasks.
  • Record repeatable vendor stops and upgrade locations.
  • Use hub visits to clean inventory.
  • Keep controller, login, and performance notes close to hub workflows.

Hexi

Expansion route covering Jade Gate Pass, Liangzhou, and Qinchuan update trail.

  • Start with main chapter unlocks.
  • Track bosses and event entries separately.
  • Update daily checklist when limited-time activities appear.
  • Keep source links beside expansion notes.

Route Tags To Add

Each map note should carry a route tag: waypoint, resource, boss, event, hidden entrance, puzzle, vendor, or return later. This keeps future updates from becoming a pile of loose notes.

Patch-Sensitive Notes

Expansion areas such as Jade Gate Pass, Liangzhou, and Qinchuan should keep source links beside the note because event entrances and priorities may move after updates.
